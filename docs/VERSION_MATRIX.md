# 基準版と版差

基準は日本ファルコム Windows Online。First の公式オンラインマニュアルを資料基準とする。同系列であっても実機差分が未確認なら同一とは断定しない。

| プロファイル | 根拠・既知の特徴 | 現在の扱い |
|---|---|---|
| WIN_ONLINE_CANON | 公式無料配布物、Windows 公式マニュアル | A 確定定数＋未確定値 null。非プレイ用参照 |
| PLAYABLE_EXPERIMENTAL_V1 | Windows A 規則の部分実装と C 暫定整数式 | 今回遊べる唯一のルールセット |
| PC98_ORIGINAL | EGG 公式紹介：初代53面 | 研究対象。互換プロファイル未実装 |
| PC98_ADVANCED | EGG 公式紹介：52＋52面、強敵回避・王の退路遮断 | 研究対象。完全 AI 未実装 |
| MD_1994 | SEGA 公式説明書：税率0〜30%、MD 固有構成 | 比較資料。Windows 数式への直接流用なし |
| Windows Original / First / Pro | ファン比較にマップ数52/20/52、Online14説 | B。マップ数・内部挙動は未追試 |

Windows 実験プロファイルの税率上限30は C。MD の A 値で Windows の確定値を代用したことにはしない。城内倍率4/3は公式の概数「王約4倍、部隊約2〜3倍」を整数化した C。維持費の拠点上限定は B 観測説を C 実験モードに採用したもの。基準版に未追試の式を追加しない。
