# 遊べるマップと登録方法

開始画面でマップを選び、「このマップで開始」を押す。プレイ中は上部メニューの「マップ選択・新しいゲーム」から開く。選択画面では時間が止まり、選び直すだけでは現在の世界は変わらない。残したい進行は開始前に保存する。「保存したゲームを読込」は保存した面と地形を復元する。

| 表示名 | ID | 内容 | 制作 |
|---|---|---|---|
| 四つの川 | four_rivers | 従来の川と橋の標準面 | 既存マップ |
| 開けた野 | open_plains | 広い平地。序盤の内政を覚えやすいが、中盤は戦線が広がる | Grok |
| 二つの渡し | twin_crossings | 川と複数の既設橋。橋の防衛・迂回が重要 | Grok |
| 境界の半島 | borderlands | 半島の内政地と中央の争奪地 | Grok |
| 継承の地峡 | succession_isthmus | 既設橋と地峡で戦い、南の海を桟橋から開く | Grok / 統合時に桟橋調整 |
| 片海 | half_sea | 海で東西に分断。地峡の攻防と北の桟橋の渡河 | Grok / 統合時に桟橋調整 |
| 渦の水路 | spiral_channel | 四つの部屋を3か所の1マス水路で順に接続する | Grok |

全7面は40×26、青国を操作する600日のゲーム。通常人口・資金・兵力などの初期値は共通。Grok制作の前半3面はPR #1 / grok/maps、今回の後半3面はPR #2 / grok/original-grammarのデータを取り込み、Codexが選択UI・再挑戦・Web配信へ統合した。各面の制作意図と元の試遊結果は [maps/](maps/) にある。

検証はGodot 4.5.2。`tests/map_grok_three.gd` は新3面を各1200 tick進め、174項目を確認する。`tests/map_selection_ui.gd` は実際のUI信号を使い、7面の選択・開始・部隊命令・保存・タイトルからの読込・同じ面への再挑戦を確認する。`tests/ui_smoke.gd` と `tests/web_viewport.mjs` で既存操作と横持ちの寸法契約も検証する。スマホ実機での操作感と、人間が600日通して遊ぶ難易度は未検証。

今後のマップ追加は `data/maps/<id>.json` を作り、Codex側で `ui/game.gd` のMAPSへID・パス・表示名・説明を登録する。全JSONはWeb出力のinclude_filterに含まれるが、配信用PCKの書き出し直しと公開更新が必要。JSONの追加やPR作成だけでは公開済みゲームには反映されない。

## 新3面の渡河と最新版AI

Grok提出時の説明・数値は旧AIの試遊記録。現在は敵も必要に応じて架橋・橋切断・修理を行うため、「プレイヤーが橋を架けなければ永遠に会わない」という挙動にはならない。敵は費用・戦力・岸の安全を確認するので、必ずすぐ架橋するわけでもない。

現行の共通ルールでは、橋上から次の水面へ橋を延ばせない。提出時の「継承の地峡」の南海は幅2、「片海」の中央海は幅3で、対岸への別経路もないため、プレイヤーでも横断を完成できなかった。初期の分断を保ち、以下の中立桟橋3セルだけを追加した。両面のJSON版番号は2、渦の水路は提出時の版1の地形をそのまま使用する。

| 面 | 追加した陸地（0始まり） | 残る架橋地点 | 完了後 |
|---|---|---|---|
| 継承の地峡 | (8,18) | (8,17) の1マス | 青・紅・金の陸地と緑が接続 |
| 片海 | (18,6)、(19,6) | (17,6) の1マス | 東西の戦場が接続 |
| 渦の水路 | 変更なし | (15,20)、(30,14)、(17,6) | 順に架橋すると4国の城が接続 |

`tests/map_original_grammar.gd` は初期の到達・分断、初期税路、通常費用と岸作業での架橋、架橋後の全城到達、各1200 tickの実戦と発展を検査する。JSON追加だけでなく、全7面の選択・開始・命令・保存・復元・再挑戦を `tests/map_selection_ui.gd` で確認する。

## 今回の統合検証

Godot 4.5.2で新3面を各1200 tick（200日）進め、地形・税路・岸からの通常費用による架橋・架橋後の全城到達を含む108/108項目に成功。7面の選択・開始・命令・保存・復元・同一面再挑戦は95/95項目に成功。

| 新マップ | 期間中の最大村数（青 / 紅 / 金 / 緑） | 最終の橋セル数 |
|---|---|---:|
| 継承の地峡 | 74 / 47 / 37 / 30 | 5 |
| 片海 | 16 / 35 / 62 / 75 | 6 |
| 渦の水路 | 32 / 48 / 37 / 22 | 9 |

橋セル数は耐久ではなく橋があるマスの数。継承の地峡は初期2、他2面は初期0。AIの架橋・修理・破壊で経路は変化する。人間が600日遊んだ難易度、スマホ実機・ブラウザ実操作は未検証。元APK・復旧用ZIPは今回も更新していない。

配信用PCK自体を読み込んだ同じ選択UI検査も95/95成功。Web寸法契約は67/67成功（Nodeのモック検査）。今回のビルド識別子: `1ba69048668a4aa0`。
