# 遊べるマップと登録方法

開始画面でマップを選び、「このマップで開始」を押す。プレイ中は上部メニューの「マップ選択・新しいゲーム」から開く。選択画面では時間が止まり、選び直すだけでは現在の世界は変わらない。残したい進行は開始前に保存する。「保存したゲームを読込」は保存した面と地形を復元する。

| 表示名 | ID | 内容 | 制作 |
|---|---|---|---|
| 四つの川 | four_rivers | 従来の川と橋の標準面 | 既存マップ |
| 開けた野 | open_plains | 広い平地。序盤の内政を覚えやすいが、中盤は戦線が広がる | Grok |
| 二つの渡し | twin_crossings | 川と複数の既設橋。橋の防衛・迂回が重要 | Grok |
| 境界の半島 | borderlands | 半島の内政地と中央の争奪地 | Grok |

全4面は40×26、青国を操作する600日のゲーム。通常人口・資金・兵力などの初期値は共通。Grok制作3面はPR #1 / grok/mapsのデータを取り込み、Codexが選択UI・再挑戦・Web配信へ統合した。各面の制作意図と元の試遊結果は [maps/](maps/) にある。

検証はGodot 4.5.2。`tests/map_grok_three.gd` は新3面を各1200 tick進め、174項目を確認する。`tests/map_selection_ui.gd` は実際のUI信号を使い、4面の選択・開始・部隊命令・保存・タイトルからの読込・同じ面への再挑戦を確認する。`tests/ui_smoke.gd` と `tests/web_viewport.mjs` で既存操作と横持ちの寸法契約も検証する。スマホ実機での操作感と、人間が600日通して遊ぶ難易度は未検証。

今後のマップ追加は `data/maps/<id>.json` を作り、Codex側で `ui/game.gd` のMAPSへID・パス・表示名・説明を登録する。全JSONはWeb出力のinclude_filterに含まれるが、配信用PCKの書き出し直しと公開更新が必要。JSONの追加やPR作成だけでは公開済みゲームには反映されない。
