# 開発資料の入口

1. [GAME_SYSTEM.md](GAME_SYSTEM.md) — 現在動いているゲームのルール、計算式、AI、命令、スマホ操作。
2. [DEVELOPMENT.md](DEVELOPMENT.md) — コードの責務、状態モデル、命令契約、保存／リプレイ、ビルド、Grok等との共同開発。
3. [UPDATE_2026-10-15.md](UPDATE_2026-10-15.md) — 住居・戦力判断・橋作業の変更と検証。
4. [RECOVERY_STATUS.md](RECOVERY_STATUS.md) — 復旧した旧版ファイルと不足していた成果物。
5. [SPEC_CANONICAL_JA.md](SPEC_CANONICAL_JA.md)、[RULE_STATUS.csv](RULE_STATUS.csv)、[ORIGINAL_TEST_PLAN.md](ORIGINAL_TEST_PLAN.md) — 原作調査の仕様、確度、観測計画。現行実装そのものの仕様とは分離する。
6. [EXPORT.md](EXPORT.md) — ネイティブ出力の参考手順。ブラウザ版はDEVELOPMENTの手順を使う。

Grok等へ渡す場合はGitHubの最新ソースと1・2をセットで渡す。元ZIP・APKは旧版であるため、開発の正本として渡さない。
