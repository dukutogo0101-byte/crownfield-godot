# Windows Online 実機試験

## 現在の実施範囲

今回の環境は Linux。公式 Windows 実行ファイルを起動して数値を測定した証跡はない。原作の実測CSVは空の入力テンプレートであり、値の空欄を0と解釈しない。配布物の入手・ZIP監査は実測と別の作業。

原作配布物が取得できても、このプロジェクトには画像・音楽・原作マップ・実行ファイルを同梱しない。検証者本人の Windows 環境に公式から入手する。ダウンロード可否・ライセンス等は公式ページを再確認する。

## 共通手順

1. Windows Online の版・実行ファイル SHA256、速度、OS、試験日、セーブ識別子を記録する。
2. 同一セーブで無操作試験を10回行い、人口・資金・移動の系列が一致するか確認する。原作の乱数シード指定は未確認。
3. 速度を固定し、動画時刻と原作の日数表示を同時に残す。観測周期を Godot の tick と同一視しない。
4. 一度に1変数だけ変更する。セーブ・録画・CSV を同じ scenario_id に結び付ける。
5. 同一入力条件を Godot fixture に写す。A の条件は差0、未知式は候補モデルを比較して境界値で追試する。
6. 実測確認済みは B→A に自動昇格させない。A は公式根拠区分として保持し、verification=measured と版・証跡を追記する。

## 合格基準

公式確定規則は個々の条件試験で差0。未確定の整数式は観測入力と出力を保存した fixture で差0を目標とする。動画だけから強度を推測して測定済み扱いしない。少なくとも2種類の境界外入力と同じ条件の複数回追試でモデルを確認する。

Godot の同一リプレイを Windows と Android の同じ版で実行し、初期・終端・可能なら各tick hashを一致させる。これは未実施。Linux 内の決定論テスト合格はクロスプラットフォーム合格を意味しない。
