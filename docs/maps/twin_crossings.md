# 二つの渡し（twin_crossings）

橋の防衛と進軍路の選択を見る面。40×26。初期の国力配置は `four_rivers` と同じ。

画面色は青 `#54b9f3`、紅 `#ee7771`、金 `#e9b959`、緑 `#8bcfa6`（id 0〜3）。JSON名は Azure / Crimson / Jade / Amber で、金と緑は名前と色が逆に見える。初期位置は北西・北東・南東・南西。

## 狙い

幅2マスの縦川（x=18〜19）と横川（y=12〜13）で四つの地域に分ける。AIは橋を架けないので、渡しは最初から架けてある（耐久8）。各方角に渡しが二つずつある。

- 北: y=4 と y=8（青と紅）
- 南: y=17 と y=21（緑と金）
- 西: x=5 と x=12（青と緑）
- 東: x=26 と x=33（紅と金）

川を渡るには2マスとも橋である必要がある。橋の両岸は平地。城の初期領地には川も橋も被せていない。

## 難易度

建設圏は川の手前で止まるので、序盤20日は開けた野と同じ速度で村が増える。40日以降は渡しの向こうでぶつかり、内政の伸びが分かれる。どの渡しを押さえるかが戦線になる。

## 到達と税

初期状態で4城は渡しを通って相互に到達できる。橋の新設も洞窟封鎖も不要。初期村の税路は自国領地だけで城につながり、`can_tax` が真。同国村の隣接違反はない。

## 試遊上の課題

- 緑（南西）はピーク15村まで伸びたあと、120日以降は3村のまま。資金と人口は残っており、部隊の永久停止ではない。西の二つの渡しをCPUが同時に守りきれず、内政地が初期村付近まで削られている。
- 紅も200日の人口が951まで落ちる。金（南東）は自地域を保ったまま14村・人口4443まで伸びる。経路の探索順（上・左・右・下）で対称配置でも結果は揃わない。
- 人間の青なら、西の渡しのどちらを守るかを選べる。CPU試遊はその選択を代行していない。
