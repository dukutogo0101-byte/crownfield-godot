# 店先の踏切（shop_crossing）

48×48。ファルコムの面データではない。フーズパニックが始まる第6面の公開図で読める部屋の仕切りと踏切だけを、このエンジンのマスに置き直した。店の名前、面の題、画像は入れていない。

原作の自国はハンバーガー屋で、城の屋根は赤だった。このゲームの自国色は青のままなので、画面の青がその位置にいる。JSONの `name` は既存面と同じ。

| id | 画面色 | JSON名 | 位置 |
|---|---|---|---|
| 0 | 青 `#54b9f3` | Azure | 中央の城。店先は左上。プレイヤー |
| 1 | 紅 `#ee7771` | Crimson | 中央の城。店先は右上。踏切が切れている |
| 2 | 金 `#e9b959` | Jade | 中央の城。店先は右下 |
| 3 | 緑 `#8bcfa6` | Amber | 中央の城。店先は左下。入口に橋がある |

初期の資金800、税率10、村の人口128、兵96、王448は既存面と同じ。城の周りの領地の形は既存面と違う。店先の部屋をその国の領地にして、城からそこまで自国のマスを1本通してある。

## 狙い

中央の広場に4つの城が並び、王同士は最初から歩いて会える。収入になる店先は四隅の部屋で、線路（このエンジンでは水面）で区切ってある。

- 青の左上、金の右下は最初から税が通る。左・上・下の空き部屋は、あとから埋める区画。
- 紅の右上だけ、城と店先のあいだの踏切が橋なし。開始時は紅の村に税が届かない。その1マスに橋を架けると店先が開く。
- 緑の左下へは、細い区画を抜けた先に最初から橋がある。そこを壊し続けると、緑の税路を断てる。

仕切りは全部水面にした。洞窟の見た目は使っていない。原作の線路は「金を払えば渡れる壁」なので、通過不能な洞窟にはしていない。

## 到達と税

Godot 4.5.2、`tests/map_shop_crossing.gd`。読み込みと `restore` は通る。

4つの城は相互に到達できる。紅の初期村2つへは、誰も到達できない。青・金・緑の初期村は `can_tax` が真。同国の村は斜めを含めて隣接していない。

右上の切れ目 `(41, 20)` は水面で橋0。左下の `(12, 45)` は橋8で、最初から渡れる。

## 1200 tick（200日）のCPU試遊

人間操作ではない。4国とも初期命令 `auto`。勝敗はつかず、4国とも生存。

| 国 | 村のピーク | 200日の村 | 200日の人口 | 200日の資金 |
|---|---:|---:|---:|---:|
| 青 Azure | 75 | 75 | 24689 | 2899 |
| 紅 Crimson | 41 | 41 | 6106 | 147 |
| 金 Jade | 102 | 101 | 19639 | 3391 |
| 緑 Amber | 77 | 77 | 13808 | 2346 |

人口は村人口＋通常部隊で、王の兵力は含まない。

紅は40日で資金0、村10まで増えたあと5まで減る。80日には資金88に戻り、200日には村41。現行の戦略AIは、自国の切れた税路を繋ぐために架橋する。開始時の遮断は残るが、CPU同士の200日では紅の店先は開き直す。

## 試遊上の課題

- 中央の4城は近い。王は城にいるあいだは飛び出しにくいが、兵は空き部屋ですぐ接触する。
- 金の右下は最初から繋がっていて部屋が広い。200日の村は101で、4国の中で一番大きい。
- 紅を急ぐなら、資金が尽きた40日前後が読みやすい。放置すると自国AIが踏切を直して税が戻る。
- 新しい橋は1マス30。原作の「直す」と「新しく架ける」の金額差は、このデータでは出していない。切れ目は橋0の水面。
- 48×48なので、いつもの40×26よりマスが細かい。部屋の縦積みを潰さないため、この面だけ広くしてある。
