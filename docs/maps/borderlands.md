# 境界の半島（borderlands）

安全な内政地と、中央の争奪地を分ける標準面。40×26。初期の国力配置は `four_rivers` と同じ。

画面色は青 `#54b9f3`、紅 `#ee7771`、金 `#e9b959`、緑 `#8bcfa6`（id 0〜3）。JSON名は Azure / Crimson / Jade / Amber。初期位置は北西・北東・南東・南西。

## 狙い

四隅は平地の半島で、既存の城と初期村を内側に収める。中央（おおよそ x=11〜28, y=9〜16）が争奪用の平地。半島から中央へは幅3マスの陸地でつなぐ。側面の海は回り込みを遅らせるが、半島の根元の荒れ地を歩けば、首根っこが塞がっても別路がある。

中央の2×2は洞窟。AIは洞窟を封鎖しないので、障害物のまま残る。四方に平地があり、城同士の道は洞窟では切れない。肩の荒れ地にも洞窟を数個置いたが、歩行用の隙間は残してある。

橋の建設も洞窟の封鎖も、この面を進める条件にしていない。

## 難易度

半島の中は村を置きやすく、中央は後から伸びる。初期部隊は半島内で、開始時の挟撃はない。標準面なので、内政に寄せるか中央へ出すかを国ごとに配分することになる。

## 到達と税

初期状態で4城は陸地経由で相互に到達できる。初期村の税路は自国領地だけを通り、`can_tax` が真。同国村は斜め隣接していない。各城の周囲8マス以内に、隣接禁止を考慮した村の建設候補が20を超える。

## 試遊上の課題

- 紅は140〜160日に19村まで中央へ出すが、200日には8村まで戻る。中央の村は壊れ、人口は半島側に残る。狙った「出先は削れ、内政地は残る」に近い。
- 緑（南西）は200日に4村まで減る。ピークは16なので開発不能ではない。半島へ押し戻されている。
- 洞窟は封鎖されない。中央の岩は回り込みが増えるだけで、新しい命令にはならない。
- 人間が青の半島に兵を残した場合の安定度は未確認。
