# 片海（half_sea）

> **最新版への統合注記（2026-10-15）**: 中央海の(18,6)・(19,6)へ中立桟橋を追加し、残る(17,6)を岸から架橋すれば東西が接続します。JSON版2。 現在の敵AIも架橋するため、敵が海を渡らないという下記の説明は旧版のものです。以下の本文・数値はGrok提出時の設計と旧AIの記録として保持しています。現行の地形・到達条件と検証は [マップ一覧](../MAPS.md) を参照してください。

40×26。初期資金・税率・村人口・兵力・城と初期村の相対配置は `four_rivers` と同じ。変えているのは地形と、城を地峡へ向ける向きだけ。

ファルコムの面データを写した面ではない。諸島戦で繰り返し出る型を、この盤の大きさに置き直している。地図は海で二つに割れ、それぞれの陸には地峡が一つある。海に新しい橋を架けるのはプレイヤーだけで、オートは架けない。壊れた橋は置いていない。CPUが修理で渡ってしまうと、この面の「海を開く判断」が消えるため。

参照したのは構造の説明だけ。[海はプレイヤーだけが橋を架ける](https://henamap.doorblog.jp/archives/77172198.html)、[森は通れるが村は置けない](https://henamap.doorblog.jp/archives/77172182.html)。

## 狙い

中央の海は x=17–19 の3マス幅で、上から下まで橋がない。西（青と緑）と東（紅と金）は初期状態で行き来できない。

西の地峡は (7–8, 12–13) の2×2。東の地峡は (30–31, 12–13) の2×2。それ以外のその行は海。戦いが始まる場所は、この細い陸だけ。

城の周囲、チェビシェフ距離5は荒れ地の垣根。通れるが、開墾するまで村は置けない。

## 1200 tick（200日）のCPU試遊

人間操作ではない。初期命令 `auto` のまま4国をCPUが進めた。Godot 4.5.2、`tests/map_original_grammar.gd`。72項目すべて成功。勝敗はつかず、4国とも生存。海は最後まで誰も架けていない。

40日と80日は左右が同じ数（40日は北が村9、南が村15。80日は北が村3、南が村13）。地峡で北が削られ、南が陸を残す。120日以降は左右が分かれ、200日には金が村39、緑が村22、青が村7、紅が村6。北の2国は生存しているが、南の内政地を取り切れていない。

## 試遊上の課題

- 放置するとプレイヤーは西の戦争しか見ない。中央の3マスを架けない限り、東は別の試合のまま終わる。架けるのはプレイヤーだけ。
- 3マスで90。初期資金800に対してはまだ安い。原作の新規橋3000より判断は軽い。ただし架けないという選択は、東を見ないという選択になる。
- 南が地峡を持ったあとに北へ押し返す動きは、200日の時点では金と緑で強さが違う。左右対称の地形でも、戦闘のあと数は揃わない。
- 人間が青を止めて操作した場合、地峡を守るか、先に海を開いて東へ出るかは未確認。
