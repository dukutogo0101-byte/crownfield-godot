# 開けた野（open_plains）

入門面。40×26。初期資金・税率・村人口・兵力・城と初期村の配置は `four_rivers` と同じ。変えているのは地形だけ。

国の呼び方は画面の色に合わせる。JSONの `name` は既存面と同じで、色と語が一致しない。

| id | 画面色 | JSON名 | 初期位置 |
|---|---|---|---|
| 0 | 青 `#54b9f3` | Azure | 北西。プレイヤー |
| 1 | 紅 `#ee7771` | Crimson | 北東 |
| 2 | 金 `#e9b959` | Jade | 南東 |
| 3 | 緑 `#8bcfa6` | Amber | 南西 |

## 狙い

川も洞窟もない広い平地で、村を増やす・兵をまとめる流れを先に覚える面。中央の荒れ地は小さい島で、最初の建設圏（城と初期村から距離6）の外に置いてある。開墾はできるが、道は塞がない。

四隅の内政地は既存面と同じ領地形。隣国の初期部隊とはマンハッタン距離15以上で、開始直後の接触も脅威圏の重なりもない。

## 難易度

序盤は脅威が小さい。40日までは4国とも村が10以上に増え、人口も揃って伸びる。障害物がないので、その後は中央で村が壊されやすく、数はピーク15前後から4〜7まで落ちる。数値そのものは既存面と同じで、難しいのは「兵を集めるタイミング」だけ。

## 到達と税

初期状態で4城はすべて相互に到達できる。橋は不要。初期村8つは自国領地だけで城とつながり、`can_tax` が真。同国の村は斜めを含めて隣接していない。

## 1200 tick（200日）のCPU試遊

人間操作ではない。初期命令 `auto` のまま4国をCPUが進めた。Godot 4.5.2、`tests/map_grok_three.gd`。勝敗はつかず、4国とも生存。通路で4サンプル以上止まった部隊はなし。

人口は村人口＋通常部隊で、王の兵力は含まない。

## 試遊上の課題

- 40日以降、平地なので戦線が固定されない。村は建つがすぐ壊される。入門なのは内政の手順で、中盤の防衛は既存面より忙しい。
- 金（南東）は200日時点で村は7あるが人口が1229まで落ちている。全滅はしていない。兵をまとめ損ねると平地では人口だけ削られる。
- 人間が青を止めて操作した場合の難易度は未確認。
